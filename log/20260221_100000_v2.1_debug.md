## 问题描述
v2.1 前端完成后，访问 3000 端口出现两个独立问题：
1. 页面始终显示 "No photos uploaded yet."，看不到任何已上传照片；
2. 图片缩略图无法加载（HTTP 400 Bad Request），详情页点击后崩溃报错 `TypeError: w.GPSLatitude.toFixed is not a function`。

---

## Bug 1：照片列表始终为空（"No photos uploaded yet."）

### 根因
Next.js（Turbopack）在**构建阶段**对 `process.env.INTERNAL_API_URL` 做了死代码消除（Dead Code Elimination）。由于 Docker 构建时该环境变量不存在，编译器将其视为 `undefined` 并直接删除，编译产物中只剩下 `process.env.NEXT_PUBLIC_API_URL`（值为 `http://localhost:8080`）。前端容器运行时，SSR 请求走向容器内的 `localhost:8080`，而 `go-core` 服务并不在前端容器的 `localhost` 上，导致每次服务端 fetch 均抛出 `ECONNREFUSED`，`getPhotos()` 返回空数组。

### 修复方案
- **`frontend/Dockerfile`**：在 `builder` 阶段通过 `ARG` / `ENV` 注入 `INTERNAL_API_URL`，使构建时编译器能识别该变量并保留运行时的动态读取逻辑：
  ```dockerfile
  ARG INTERNAL_API_URL=http://go-core:8080
  ENV INTERNAL_API_URL=${INTERNAL_API_URL}
  ```
- **`docker-compose.yml`**：在 `frontend` 服务的 `build` 块中添加 `args`，将 `INTERNAL_API_URL` 传入构建阶段：
  ```yaml
  build:
    context: ./frontend
    args:
      - INTERNAL_API_URL=http://go-core:8080
  ```

## Bug 2：图片 400 错误 & 详情页崩溃

### 根因 A：图片 400 Bad Request
Next.js `<Image>` 组件默认使用服务端代理（`/_next/image`）对图片进行优化。代理在容器内运行，向 `NEXT_PUBLIC_MINIO_URL`（`http://localhost:9000`）发起请求，而容器内的 `localhost` 上没有 MinIO，导致所有缩略图/代理图请求返回 400。

### 根因 B：`GPSLatitude.toFixed is not a function`
`PhotoDetail.tsx` 中的 `ExifData` TypeScript 接口与 Go Core API 实际返回的 JSON 结构完全不匹配：

| 接口定义（错误）| API 实际返回字段 | 类型差异 |
|---|---|---|
| `Make: string` + `Model: string` | `CameraModel: string` | 字段名错误 |
| `FNumber: number` | `Aperture: string` | 字段名+类型错误 |
| `ISOSpeedRatings: number` | `ISO: string` | 字段名+类型错误 |
| `ExposureTime: string` | `ShutterSpeed: string` | 字段名错误 |
| `GPSLatitude: number` | `GPSLatitude: string`（空串 `""`）| 类型错误 |
| `GPSLongitude: number` | `GPSLongitude: string`（空串 `""`）| 类型错误 |

GPS 判断条件为 `exif.GPSLatitude !== 0`，空字符串 `""` 不等于 `0`，条件为 `true`，随即调用字符串的 `.toFixed()` 方法，抛出 `TypeError` 导致详情页白屏崩溃。

### 修复方案
- **`frontend/src/components/PhotoGrid.tsx`**：`<Image>` 添加 `unoptimized` 属性，让浏览器直接从 MinIO 拉取图片，绕过服务端代理。
- **`frontend/src/components/PhotoDetail.tsx`**：
  - `<Image>` 同样添加 `unoptimized`；
  - 重写 `ExifData` 接口，字段名与类型与 API 实际响应严格对齐（全部改为 `string`）；
  - EXIF 渲染引用从 `Make/Model/FNumber/ISOSpeedRatings/ExposureTime` 改为 `CameraModel/Aperture/ISO/ShutterSpeed`；
  - GPS 显示条件改为 `!!exif.GPSLatitude`（检查非空字符串），数值通过 `parseFloat(...).toFixed(4)` 转换后展示。
- **`frontend/src/app/@modal/(.)photo/[id]/page.tsx`** 和 **`frontend/src/app/photo/[id]/page.tsx`**：同步更新 `ExifData` 接口定义。

### 附加修复
- **`frontend/next.config.ts`**：`remotePatterns` 添加 `minio:9000`（容器内部主机名）白名单，为后续服务端场景预留。
- **`frontend/src/app/layout.tsx`**：页面标题从默认的 "Create Next App" 修正为 "Photogiraffe Gallery"。
