# v6.3 — 相册公开分享（Share Links）

**日期**: 2026-02-23  
**版本**: v6.3  
**分支**: s4.6full-stack

---

## 目标

实现基于 Token 的公开照片分享功能。用户可以为任意照片生成一条不需要登录即可访问的分享链接，链接支持吊销。

---

## 后端变更（go-core）

### `models/models.go`
- 新增 `ShareLink` 模型：
  ```go
  type ShareLink struct {
      gorm.Model
      PhotoID   uint       `gorm:"not null;index"`
      UserID    uint       `gorm:"not null;index"`
      Token     string     `gorm:"not null;uniqueIndex"`
      ExpiresAt *time.Time // nil = 永不过期
      IsRevoked bool       `gorm:"default:false"`
  }
  ```

### `database/db.go`
- `AutoMigrate` 中追加 `&models.ShareLink{}`

### `main.go`
- 新增 import：`"crypto/rand"`, `"encoding/hex"`
- 新增辅助函数 `generateShareToken()` — 生成 32 字节密学随机 hex token
- 新增 4 条 API 路由：
  | 方法 | 路径 | 鉴权 | 说明 |
  |------|------|------|------|
  | POST | `/api/photos/:id/share` | JWT | 为指定照片生成或返回现有未吊销分享 token |
  | GET | `/api/photos/:id/share` | JWT | 列出该照片所有有效分享链接 |
  | DELETE | `/api/photos/:id/share/:token` | JWT | 吊销指定分享链接 |
  | GET | `/share/:token` | **无需 JWT** | 公开接口，返回照片信息 + MinIO 预签名 URL |

## 前端变更（frontend）

### 新增文件
- `src/app/api/photos/[id]/share/route.ts` — GET+POST 代理至 Go Core
- `src/app/api/photos/[id]/share/[token]/route.ts` — DELETE 代理至 Go Core
- `src/app/api/share/[token]/route.ts` — 公开代理（不转发 Authorization）
- `src/app/share/[token]/page.tsx` — 公开分享展示页（Client Component，显示照片缩略+EXIF+复制链接按钮）

### 修改文件
- `src/components/ClientLayout.tsx` — PUBLIC_PATHS 追加 `/share/`（跳过 JWT 检查）
- `src/components/PhotoDetail.tsx` — 新增 Share 面板，包含：
  - "Create Link" 按钮 → `POST /api/photos/:id/share`
  - 创建成功后显示完整 URL
  - "Copy Link" 按钮（含 Copied! 反馈）
  - "Revoke" 按钮（仅清除前端状态；完整吊销可通过 DELETE 接口）
  - 图标：`Share2`, `Link`, `Copy`, `Check`（来自 lucide-react）

## 测试结果

```bash
# 登录获取 token
ACCESS=$(curl -s -X POST http://localhost:8080/api/auth/login \
  -H "Content-Type: application/json" \
  -d '{"username":"admin","password":"admin123"}' | python3 -c "import sys,json; print(json.load(sys.stdin)['access_token'])")

# 创建分享链接
curl -s -X POST "http://localhost:8080/api/photos/18/share" \
  -H "Authorization: Bearer $ACCESS"
# 响应: {"created_at":"...","expires_at":null,"share_url":"/share/9a1e6875...","token":"9a1e6875..."}

# 公开访问（无 JWT）
curl -s "http://localhost:8080/share/9a1e6875..." | python3 -m json.tool | head -5
# 响应: {"photo": {"exif": {...}, ...}, "proxy_url": "...", "thumb_url": "..."}

# 前端代理
curl -sI http://localhost:3000/share/9a1e6875...
# HTTP/1.1 200 OK ✓

# 前端 API 代理
curl -s http://localhost:3000/api/share/9a1e6875... | python3 -m json.tool | head -5
# 返回照片数据 ✓
```

所有测试通过。
