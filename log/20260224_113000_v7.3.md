# v7.3 — 相册/集合管理 (2026-02-24 11:30)

## 目标
为用户提供照片组织能力：创建命名相册，批量归类照片，相册分享，以及公开相册浏览页。

## 实现内容

### 1. 数据模型 (`go-core/models/models.go`)
```go
type Album struct {
    gorm.Model
    UserID       uint
    Name         string
    Description  string
    CoverPhotoID *uint    // 可选封面
    ShareToken   string   `gorm:"uniqueIndex"` // 空 = 未分享
    Photos       []Photo  `gorm:"many2many:album_photos;"`
}

type AlbumPhoto struct {
    AlbumID  uint      `gorm:"primaryKey"`
    PhotoID  uint      `gorm:"primaryKey"`
    AddedAt  time.Time `gorm:"autoCreateTime"`
}
```
- AutoMigrate 自动建表 `albums` + `album_photos`（`go-core/database/db.go`）

### 2. 后端 API (`go-core/main.go` — 9 个端点)
| 方法 | 路径 | 说明 |
|------|------|------|
| POST | `/api/albums` | 创建相册 |
| GET | `/api/albums` | 当前用户相册列表（含 photo_count） |
| GET | `/api/albums/:id` | 相册详情（Preload Photos） |
| PUT | `/api/albums/:id` | 更新名称/描述 |
| DELETE | `/api/albums/:id` | 删除相册（照片不受影响） |
| POST | `/api/albums/:id/photos` | 批量添加照片（ON CONFLICT DO NOTHING） |
| DELETE | `/api/albums/:id/photos/:photo_id` | 移除单张照片 |
| POST | `/api/albums/:id/share` | 生成 32 位 hex 分享 Token |
| DELETE | `/api/albums/:id/share` | 撤销分享 |
| GET | `/share/album/:token` | 公开相册（无鉴权，返回预签名缩略图 URL） |

### 3. 前端 API 代理路由
- `api/albums/route.ts` — GET（列表）+ POST（创建）
- `api/albums/[id]/route.ts` — GET（详情）+ PUT（更新）+ DELETE（删除）
- `api/albums/[id]/photos/route.ts` — POST（添加照片）
- `api/albums/[id]/photos/[photo_id]/route.ts` — DELETE（移除照片）
- `api/albums/[id]/share/route.ts` — POST（生成分享）+ DELETE（撤销）
- `api/share/album/[token]/route.ts` — GET（公开相册代理）

### 4. 相册列表页 (`frontend/src/app/albums/page.tsx`)
- 卡片式网格布局，显示照片数量、分享状态
- 内联创建表单（名称 + 简介），实时刷新
- Hover 复现"删除"按钮（照片不受影响）

### 5. 相册详情页 (`frontend/src/app/albums/[id]/page.tsx`)
- 照片缩略图网格（`/api/image?path=thumb/…`）
- 内联编辑相册名称/描述（铅笔图标触发）
- 分享控制：生成链接 / 复制链接 / 撤销分享（`Link2` / `Link2Off` 图标）
- Hover 显示"从相册移除"按钮

### 6. 公开相册分享页 (`frontend/src/app/share/album/[token]/page.tsx`)
- 无需登录（PUBLIC_PATHS 已含 `/share/` 前缀）
- 展示相册名称、描述、照片数量及预签名缩略图网格
- Aperture 品牌标识头部

### 7. AddToAlbumModal 组件 (`frontend/src/components/AddToAlbumModal.tsx`)
- 底部弹出（移动端）/ 居中弹出（桌面端）
- 列出当前用户所有相册，点击即添加（可重复选多个相册）
- ✅ /Loader 状态区分已添加 / 添加中
- 内嵌"新建相册"子表单，创建后立即执行添加

### 8. BatchActionBar 更新 (`frontend/src/components/BatchActionBar.tsx`)
- 新增可选 `onAddToAlbum?: () => void` prop
- 显示琥珀色"相册"按钮（`Images` 图标），任意选中时可见

### 9. 主列表页更新 (`frontend/src/app/page.tsx`)
- 新增 `albumModalOpen` state
- `onAddToAlbum={selectedIds.size > 0 ? () => setAlbumModalOpen(true) : undefined}`
- 渲染 `<AddToAlbumModal>` 当 `albumModalOpen` 时

### 10. ClientLayout 导航 (`frontend/src/components/ClientLayout.tsx`)
- 新增 `Images` 图标 import
- MapPin 之后添加 `/albums` nav 链接（所有已登录用户可见）
