# 日志: 2026-02-20 12:00:00 (v2.0)

## 实际修改方案
按照 Phase 2 Step 1 的规划，实现了深度 EXIF 解析与元数据引擎。在 Python Worker 处理图片时，提取专业的摄影参数，并通过 Go Core API 持久化到 PostgreSQL 数据库中。

## 修改部分
1. **Go Core API 增强**:
   - 在 `go-core/models/models.go` 中，更新了 `ExifData` 结构体，增加了 `GPSLatitude`, `GPSLongitude`, `Software`, `DateTimeOriginal` 等字段。
   - 在 `go-core/main.go` 中，更新了 `/internal/photos/:id/status` 接口，使其能够接收 JSON payload 中的 `exif_data` 对象，并将其保存到 `exif_data` 表中，与对应的 `Photo` 记录关联。
2. **Python Worker 增强**:
   - 在 `python-worker/requirements.txt` 中添加了 `exifread` 库，用于更稳健地提取 RAW/HEIF/JPEG 的 EXIF 信息。
   - 在 `python-worker/main.py` 中，重构了 EXIF 提取逻辑：
     - 首先尝试使用 `exifread` 直接解析文件流（适用于 JPEG, TIFF, RAW）。
     - 如果直接解析失败或未找到标签（例如 `.HIF`/HEIF 格式），则回退到使用 `Pillow` (结合 `pillow-heif`) 提取的 `info['exif']` 字节流，剥离头部后再次使用 `exifread` 解析。
   - 成功提取了相机型号、镜头型号、焦距、光圈、快门速度、ISO、色彩空间、软件版本和拍摄时间等信息，并将其格式化后发送给 Go Core API。
