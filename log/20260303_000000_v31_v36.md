## 变更摘要

### Phase 31 — 照片评级 & 颜色标签

#### go-core/models/models.go

`Photo` struct 新增字段：

```go
Rating     int    `gorm:"default:0"`   // 0=未评级, 1–5 星
ColorLabel string `gorm:"default:''"` // "" | red | orange | yellow | green | blue | purple
```

#### go-core/main.go — 新增端点

| Method | Path | 说明 |
|--------|------|------|
| PATCH | /api/photos/:id/rating | 设置单张评级 0-5（0=清除）|
| PATCH | /api/photos/:id/color-label | 设置颜色标签 |

- 404：photo 不存在或不属于当前用户
- bulk handler 新增 `set_rating`、`set_color_label` actions（struct 扩展 `Rating int`、`ColorLabel string`）
- `GET /api/photos/search` 新增查询参数 `rating_min`（≥N 星）、`color_label`（精确匹配）

#### Frontend

- `PhotoDetail.tsx`：星级评分 UI（5 颗星，点同颗清除），颜色标签圆点选择器（6 色）
- `PhotoGrid.tsx`：卡片右上角颜色圆点（常显），右下角星级徽标（hover 显示）
- 代理路由：`photos/[id]/rating/route.ts`（PATCH），`photos/[id]/color-label/route.ts`（PATCH）

### Phase 32 — 标签管理

#### go-core/main.go — 新增端点

| Method | Path | 说明 |
|--------|------|------|
| GET | /api/tags | 列出当前用户所有 tag 及使用数 |
| PUT | /api/tags | 重命名 tag `{old_name, new_name}` |
| POST | /api/tags | 合并 tag `{source, target}`（source → target，去重）|
| DELETE | /api/tags/:name | 从所有照片中删除该 tag |

- 所有操作遍历 photos（tags 字段为 `*string` JSON 数组），原地修改后批量写回
- 缺少 `old_name`/`new_name`/`source`/`target` 字段时 → 400

#### Frontend

- `search/page.tsx`：标签管理面板（可展开），含重命名/合并/删除表单 + 标签列表
- 代理路由：`tags/route.ts`（GET/PUT/POST），`tags/[name]/route.ts`（DELETE）

## 架构说明

- `StorageQuotaBytes`/`StorageUsedBytes` 已入库但上传配额检查逻辑（超额拒绝）未启用，留供后续 Phase 激活
- 通知创建钩子（`createNotification` helper）预留但未在 SSE 广播点自动调用，避免副作用
- EXIF 元数据编辑为**纯 DB 写入**，不回写原始文件（设计决定）
- `batch-date-shift` 仅更新 `taken_at IS NOT NULL` 的照片，`offset_seconds` 可为负值（回拨时间）
