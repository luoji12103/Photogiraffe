## Summary

Added AI-powered adjust-parameter inference. User clicks "Suggest Params" in the sidebar; the system dispatches a vision-LLM job that analyses the proxy WebP and returns five adjustment values: `exposure`, `brightness`, `contrast`, `saturation`, `tonemap`. Results are persisted on the Photo model as `inferred_params` (jsonb) and the frontend shows a card with a one-click "Apply Suggestion" button.

## Architecture

```
User clicks "Suggest Params"
  → POST /api/photos/:id/infer-params (Next.js proxy)
    → go-core validates photo + AI config
    → PublishInferParamsTask → Redis infer_params_queue stream
      → Python Worker xreadgroup
        → download proxy WebP from MinIO
        → call LLM (OpenAI-compatible / Google / Anthropic)
        → _extract_json + key validation / defaults
        → PUT /internal/photos/:id/inferred-params
          → go-core writes photo.InferredParams (jsonb)
  → Frontend polls GET /api/photos/:id every 3 s
    → InferredParams set → parse + coerce AdjustParams
    → show suggestion card with "Apply Suggestion"
      → setAdjustParams(inferredSuggestion)
        → WebGL render updates live
```

**LLM prompt** (`INFER_PARAMS_PROMPT`): structured prompt requesting a strict JSON object with 5 keys; uses `response_format: {type: "json_object"}` for OpenAI-compatible and Google's `response_mime_type: "application/json"` to maximise clean output. Regex-based `_extract_json()` handles any residual markdown fences from Anthropic.
