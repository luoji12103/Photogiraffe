## 目标

Phase 3 Step 1：为 Python Worker 添加 ICC Profile 感知型色彩空间检测与精确 sRGB 转换，并将检测结果持久化到数据库，前端以颜色徽章展示色彩空间信息。

---

## 变更摘要

### 1. `python-worker/main.py`

新增两个辅助函数（位于 `process_image` 前）：

**`get_icc_profile_name(img, is_raw=False) -> str`**
- 优先级：嵌入式 ICC profile blob → HEIF NCLX profile → 返回 `"sRGB"`  
- NCLX color_primaries 映射：`1=sRGB`, `9=Rec. 2020`, `12=Display P3`  
- Sony HIF 文件使用 NCLX（color_primaries=1），无嵌入 ICC blob，正确返回 `"sRGB"`

**`convert_to_srgb(img) -> Image.Image`**
- 使用 `ImageCms.buildTransformFromOpenProfiles` + `Intent.PERCEPTUAL` 精确转换
- 支持 RGB / CMYK / LAB / YCbCr 等多种源模式
- 无 ICC profile 时退化为 `img.convert("RGB")`（向后兼容）
- 转换失败时记录 WARNING 并回退，不抛出异常

**`process_image` 函数修改（两处）：**
1. 在生成代理图像前调用 `get_icc_profile_name(img, is_raw)` → 写入 `exif_data["ICCProfileName"]`
2. 将原 `if img.mode != "RGB": img = img.convert("RGB")` 替换为 `img = convert_to_srgb(img)`

## 技术细节说明

| 情况 | 处理路径 |
|------|---------|
| JPEG/TIFF 含嵌入 ICC blob | `ImageCmsProfile` → 读取 profile name |
| Sony HEIF/HIF (NCLX) | `nclx_profile.color_primaries` → 映射到人类可读名称 |
| RAW 文件 (rawpy) | 直接返回 `"sRGB"`（rawpy 输出即 sRGB-like 数据） |
| 无任何 profile 信息 | 返回 `"sRGB"`（保守默认值）|

关于 `ImageCms`：
- `PIL.features.check('lcms2')` 返回 False（警告误报）
- 但 `ImageCms.buildTransformFromOpenProfiles` 实际功能正常（LCMS2 已编译进 Pillow）
- 经验证 Transform 构建和 `applyTransform` 执行均无异常
