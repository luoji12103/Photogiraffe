# v6.5 — 生产部署加固 (2026-02-23 11:00)

## 目标
为生产环境增加 Nginx 反向代理、请求限速与邀请码注册机制，全面提升系统安全性。

## 实现内容

### 1. Nginx 反向代理 (`nginx/nginx.conf` + `docker-compose.yml`)
- 新增 `nginx:1.27-alpine` 服务，对外唯一暴露端口 80
- frontend 端口绑定改为 `127.0.0.1:3000:3000`（不再对外直接暴露）
- 三条限速 Zone：
  - `auth_limit`：5r/m（burst=5）— 用于 `/api/auth/(login|register|refresh)`
  - `api_limit`：60r/m（burst=20）— 用于所有其他 `/api/` 路由
  - `general`：120r/m（burst=30）— 用于前端页面
- Upstream 配置：`frontend → frontend:3000`，`go_core → go-core:8080`
- `/share/` 路由直通 go_core（无限速，供分享链接访问）

### 2. Fiber limiter 中间件 (`go-core/main.go`)
- 引入 `github.com/gofiber/fiber/v2/middleware/limiter`
- `authLimiter`：10 req/min per IP，Key = `c.IP()`
- 应用于 `POST /api/auth/login` 和 `POST /api/auth/register`
- 双层限速（nginx + 应用层），防止 IP 轮换绕过

### 3. InviteCode 模型 (`go-core/models/models.go`, `go-core/database/db.go`)
```go
type InviteCode struct {
    gorm.Model
    Code      string     `gorm:"not null;uniqueIndex"`
    CreatedBy uint       `gorm:"not null;index"`
    UsedBy    *uint      // nil = 未使用
    UsedAt    *time.Time // nil = 未使用
    ExpiresAt *time.Time // nil = 永不过期
}
```
- AutoMigrate 自动建表

### 4. 邀请码 API (`go-core/main.go`)
- `POST /api/admin/invite-codes`：生成 16 位大写 hex 码（SuperAdmin only）
- `GET /api/admin/invite-codes`：列出所有邀请码（SuperAdmin only）
- `DELETE /api/admin/invite-codes/:id`：软删除邀请码（SuperAdmin only）

### 5. require_invite 功能旗标
- `defaultFlags` 中新增 `{Name: "require_invite", IsEnabled: false}`
- 注册时：若 flag 开启，需携带 `invite_code` 字段；码不存在或已使用则返回 400
- 成功注册后，InviteCode 记录更新 `UsedBy`、`UsedAt`

### 6. 公开 feature flag 端点
- `GET /api/feature/:name` 移除 `requireJWT()` 中间件
- 响应添加 `enabled` 字段（与 `is_enabled` 同义，方便前端读取）

### 7. 前端 — 注册页面 (`frontend/src/app/register/page.tsx`)
- `useEffect` on mount：fetch `/api/feature/require_invite`
- 若 `enabled=true`，显示琥珀色边框的邀请码输入框（monospace 大写字体）
- `KeyRound` 图标标识邀请码字段

### 8. 前端 — AuthContext (`frontend/src/context/AuthContext.tsx`)
- `register()` 方法增加可选参数 `inviteCode?: string`
- 当存在时，向请求体中附加 `invite_code` 字段

### 9. 前端 — Admin 页面 (`frontend/src/app/admin/page.tsx`)
- 新增第三个 tab：邀请码管理（`KeyRound` 图标）
- 一键生成按钮（调用 `POST /api/admin/invite-codes`）
- 列表展示：Code（monospace）、创建时间、已用/未用状态、一键复制
- `FLAG_LABELS` 新增 `require_invite: "邀请码注册"` 条目

### 10. 新增前端 API 路由
- `frontend/src/app/api/feature/[name]/route.ts`：公开 feature flag 代理
- `frontend/src/app/api/admin/invite-codes/route.ts`：邀请码 GET + POST 代理
