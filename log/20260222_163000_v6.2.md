# Photogiraffe v6.2 变更日志

## 版本信息
- 版本：v6.2
- 日期：2026-02-22
- 对应 Phase：Phase 6 Step 2

## 变更内容

### 新增
- `public/manifest.json`：PWA Web App Manifest，支持 standalone 安装，dark theme
- `public/sw.js`：Service Worker，三种缓存策略：
  - `./_next/static`：Cache First（永久缓存，immutable hash）
  - `/api/image`：Cache First + 7 天 TTL（代理图片离线可访问）
  - `/api/auth/*`：Network Only（不缓存鉴权接口）
  - 其他 `/api/*`：Network First + 降级缓存
  - 页面导航：Network First + 离线降级首页
- `public/icons/icon.svg`：应用 SVG 图标（aperture 主题）
- `src/components/ServiceWorkerRegistrar.tsx`：客户端 SW 注册组件
- `src/app/layout.tsx`：添加 PWA 相关 metadata（manifest, appleWebApp, icons, viewport）

### 修改
- `src/components/ClientLayout.tsx`：AppHeader 移动端优化（gap/px, 用户名 hidden sm:block）
- `src/app/admin/page.tsx`：
  - 外层 padding 从 `p-8` 改为 `px-4 sm:px-6 lg:px-8 py-6 sm:py-8`
  - 表格添加 `overflow-x-auto` + `min-w-[500px]`（移动端横向滚动）
  - 邮箱/注册时间列在小屏幕隐藏（hidden sm:table-cell / hidden md:table-cell）
