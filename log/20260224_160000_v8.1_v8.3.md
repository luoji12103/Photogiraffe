## 功能概述

### v8.1 Dashboard Stats
- `GET /api/stats`：返回 9 项仪表盘指标
  - `total_photos`, `completed_photos`, `ai_analyzed`, `albums`, `presets`
  - `recent_uploads`：最近 14 天每日上传趋势（按日期分组）
  - `top_cameras`, `top_lenses`：Top-5 最常用相机/镜头
  - `color_spaces`：色彩空间分布
- 前端 `/dashboard` 页面：5 个统计卡、14 天趋势 mini 条形图、相机/镜头/色彩空间排行条形图
- Next.js API proxy：`/api/stats` → go-core

### v8.3 Advanced Search
- `GET /api/photos/search`：多维照片搜索
  - 文本关键词（`q`）：JOIN exif_data，支持路径/拍摄设备模糊匹配
  - 相机型号（`camera`）、镜头（`lens`）
  - ISO 范围（`iso_min`, `iso_max`）
  - 拍摄日期范围（`date_from`, `date_to`）
  - GPS 地理围栏（`lat`, `lng`, `radius_km`，使用 Haversine 公式近似 bounding box）
  - 色彩空间（`color_space`）
  - 分页（`page`, `limit`）
  - 返回：`{ photos, total, page, limit, total_pages }`
- 前端 `/search` 页面：可折叠过滤面板、结果瀑布流、分页
- Next.js API proxy：`/api/photos/search` → go-core
- 导航栏：新增搜索（放大镜）和仪表盘（LayoutDashboard）图标

## Bug 修复

### Albums share_token 唯一约束冲突
- **根因**：`POST /api/albums` 创建 album 时 `ShareToken=""` 空字符串，GORM 软删除后记录仍在 DB 中，导致第二次创建时触发 `idx_albums_share_token` unique index 冲突（500 错误）
- **修复**：创建 album 时调用 `generateShareToken()` 生成唯一初始 token，不再使用空字符串
- **影响**：现有已有 share_token="" 的软删除记录不受影响；新建 album 一律有唯一 token
