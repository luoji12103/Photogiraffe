## 功能概述

### v12.1 — 修复 2 项 pre-existing 集成测试失败

**Bug 1：Returned preset ID matches（测试项 #105 左右）**

- **根因**：`GET /api/photos/:id/preset` 返回 `{"preset": {...}}`，测试执行 `d.get("ID") or d.get("id")` 在 JSON 顶层找不到 ID 字段（ID 嵌套在 preset 对象内部）
- **修复**（`go-core/main.go`）：响应改为
  ```go
  fiber.Map{"preset": preset, "ID": preset.ID, "id": preset.ID}
  ```
  将 ID 同时暴露在顶层，向后兼容旧客户端

**Bug 2：public photos only (no private)（测试项 #120 左右）**

- **根因**：`PublicPhoto` 内部 struct 缺少 `is_public` 字段，序列化 JSON 返回无该键，测试 `p.get("is_public", False)` 对所有返回对象均得到 `False`
- **修复**（`go-core/main.go`）：`PublicPhoto` struct 增加
  ```go
  IsPublic bool `json:"is_public"`
  ```
  公开相册路由已过滤 `WHERE is_public=true`，故直接赋值 `true`

## 技术笔记

- `PublicPhoto` struct 是 handler 内部局部 struct，不是 models.go 的 GORM model，只需修改序列化字段
- `/api/profile` 和 `/api/stats` 是两个独立接口，profile 页面用 `Promise.all` 并行请求减少等待
- pg-* token 全部定义在 `frontend/src/app/globals.css`，无需改动组件样式文件
