# v7.2 — 照片对比视图 (2026-02-24 10:00)

## 目标
支持同时选中两张照片进行并排对比，含独立调色面板与 EXIF 差异高亮，帮助用户评估相机参数或后期调整的差异。

## 实现内容

### 1. CompareView 组件 (`frontend/src/components/CompareView.tsx`)
- 左右分栏布局，A / B 各自独立的 `<GLCanvas>` 渲染通道
- 每侧独立 `AdjustParams` 状态，可单独调整曝光/对比度/饱和度等
- 顶部文件名标签带颜色区分（蓝色 A，紫色 B）
- **"显示调整面板"**按钮展开 / 折叠各侧的 `<AdjustPanel>`
- **"交换"**按钮（桌面端悬浮在中央分割线，移动端在 EXIF 表头行）：同时交换照片与对应调参状态
- 底部 EXIF 对比表格（8 项参数）：差异行以琥珀色背景 + `≠` 标识，相同行显示 `=`
- 使用 `useDisplayDetect()` 传递色彩空间给 GLCanvas（wide-gamut 支持）

### 2. 对比页面 (`frontend/src/app/compare/page.tsx`)
- 路由：`/compare?a=<photoId>&b=<photoId>`
- `<Suspense>` 包裹解决 `useSearchParams()` SSR 水合问题
- 并发 `authFetch` 同时拉取两张照片完整数据（含 ExifData）
- 顶部导航栏：返回按钮（`router.back()`）+ 照片 ID 提示
- 加载 / 错误状态优雅降级（Loader2 spinner / 错误文字）
- 纯前端，无需新建 API 路由（复用现有 `GET /api/photos/:id`）

### 3. BatchActionBar 更新 (`frontend/src/components/BatchActionBar.tsx`)
- 新增可选属性 `onCompare?: () => void`
- **仅当 `selectedCount === 2` 且 `onCompare` 存在时**，才渲染紫色"对比"按钮
- 使用 `GitCompareArrows`（lucide-react）图标

### 4. 主列表页更新 (`frontend/src/app/page.tsx`)
- 新增 `useRouter` import
- 新增 `handleCompare()` 函数：从 `selectedIds` 取两个 id，`router.push('/compare?a=&b=')`
- BatchActionBar 传入 `onCompare={selectedIds.size === 2 ? handleCompare : undefined}`
