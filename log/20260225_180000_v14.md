# v14 — 相册批量导出：ZIP/PDF + 冲印规格裁切

**Commit：** `3f091da`
**Date：** 2026-02-25

---

## 功能概述

新增相册级别的批量导出能力，支持将相册内所有照片打包为 ZIP 压缩包或 PDF 文档，并内置冲印规格居中裁切（4×6″、5×7″、A4、正方形）。同时在单张照片导出面板添加冲印规格选项。

---

### v14.1 — Go Core 数据模型 + 相册导出 API

**数据模型变更**（`go-core/models/models.go`）：
```go
type ExportJob struct {
    gorm.Model
    PhotoID       uint       `gorm:"not null;index"`
    AlbumID       *uint      `gorm:"index"`            // non-nil for album export jobs
    JobType       string     `gorm:"default:'photo'"`  // photo | album
    UserID        uint       `gorm:"not null;index"`
    Status        string     `gorm:"default:'pending'"`
    ExportOptions string     `gorm:"type:jsonb"`
    OutputPath    string
    ErrorMessage  string
    CompletedAt   *time.Time
}
```

**队列扩展**（`go-core/queue/redis.go`）：
- 新增 `PublishAlbumExportTask(jobID uint, albumID uint, optsJSON string) error`

**新增 API 端点**（`go-core/main.go`）：

| Method | Path | Auth | 说明 |
|--------|------|------|------|
| POST | `/api/albums/:id/export` | JWT（相册拥有者）| 创建 ExportJob（JobType=album），推入 export_queue |
| GET | `/api/albums/:id/exports` | JWT（相册拥有者）| 返回该相册全部 ExportJob 列表 |
| GET | `/internal/albums/:id/photos` | X-Internal-Secret | Worker 获取相册所有已完成照片（含 EXIF copyright/creator）|
