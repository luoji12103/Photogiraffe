**时间**: 2026-02-22 08:15

## 本次变更目标

在 v5.0 JWT 认证基础上，实施用户级数据隔离。每个用户只能访问并操作自己的照片与预设；SuperAdmin 可查看所有数据。

## 架构设计要点

### 归属检查模式
```go
if role != "SuperAdmin" && photo.UserID != uid {
    return c.Status(fiber.StatusForbidden).JSON(fiber.Map{"error": "Access denied"})
}
```

### Gallery CSR 加载模式
```tsx
useEffect(() => {
  if (!user) return;
  authFetch("/api/photos")
    .then(res => res.ok ? res.json() : Promise.reject())
    .then(data => setPhotos(data))
    .finally(() => setLoading(false));
}, [user, authFetch]);
```

### 上传后刷新列表
`page.tsx` 向 `UploadPanel` 传入 `onUploadComplete` 回调，上传完成后调用 `authFetch("/api/photos")` 重新加载。

## 测试结果

```bash
# 无 JWT 访问 → 401
GET /photos (no token) → 401 {"error":"Missing or invalid Authorization header"} ✓

# 有 JWT 访问 → 200，返回当前用户照片（user_id 过滤）
GET /photos (Bearer token) → 200 [] (admin 用户暂无照片) ✓

# 跨用户访问 → 403
GET /photos/2 (user_id=1 的照片，以 admin user_id=2 访问) → 403 {"error":"Access denied"} ✓

# 预设隔离
POST /api/presets (as admin) → 201 ✓
GET /api/presets (as admin) → [{"ID":1, ...}] ✓
GET /api/presets (as user2) → [] ✓

# 前端代理
GET http://localhost:3000/api/photos (no token) → 401 ✓
GET http://localhost:3000/api/photos (with token) → 200 [] ✓

# 构建
docker compose build go-core frontend → exit 0 ✓
```
