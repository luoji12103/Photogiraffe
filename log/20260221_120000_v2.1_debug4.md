# 日志: 2026-02-21 12:00:00 (v2.1_debug4)

## 问题描述
在照片详情页点击右上角 X 按钮无法正常返回主页，页面没有响应或停留在当前路由。

---

## 根因

### Next.js 并行路由 + 拦截路由机制
项目使用了 Next.js 的 Parallel Routes（`@modal`）和 Intercepting Routes（`(.)photo/[id]`）：
- 从画廊点击照片时，Next.js 拦截导航，在当前主页（`/`）之上以模态层渲染 `@modal/(.)photo/[id]/page.tsx`，浏览器地址栏变为 `/photo/[id]`，但**历史栈底仍是 `/`**
- 此时 X 按钮使用的是 `<Link href="/" scroll={false}>`，触发的是对 `/` 的**硬导航（push）**
- Next.js 的 App Router 认为从 `/photo/[id]` 导航到 `/` 是一个新的页面跳转，并不会以"关闭模态"的形式处理，`@modal` slot 的清空逻辑没有正确触发，导致返回失败或出现闪烁

### 正确的关闭方式
Next.js 官方文档指出，关闭拦截路由模态的标准做法是调用 `router.back()`，这会执行历史回退，Router 识别到是从拦截路由退出，自动恢复 `@modal` slot 为 `default.tsx`（空），画廊页面重新呈现。

---

## 修复方案

将 `PhotoDetail.tsx` 中的 X 按钮从 `<Link>` 改为 `<button>`，点击时调用 `handleClose()`：

```tsx
const handleClose = () => {
  // router.back() 关闭拦截路由模态并返回画廊；
  // 若从地址栏直接访问（无历史记录），fallback 到主页
  if (window.history.length > 1) {
    router.back();
  } else {
    router.push("/");
  }
};
```

两种场景均正确处理：
| 场景 | 行为 |
|---|---|
| 从画廊点击照片进入（模态模式）| `router.back()` 回退，`@modal` slot 关闭，画廊恢复 |
| 直接在地址栏输入 `/photo/[id]`（全页模式）| `history.length > 1` 为 false 时，`router.push("/")` 跳回主页 |

---

## 修改文件清单
- `frontend/src/components/PhotoDetail.tsx`：
  - 移除 `import Link`，新增 `import { useRouter }`
  - 组件内增加 `const router = useRouter()` 和 `handleClose` 函数
  - X 按钮从 `<Link href="/" scroll={false}>` 改为 `<button onClick={handleClose}>`

## 验证结果
重建并重启前端容器后：
- 从画廊点击照片 → 进入详情页 → 点击 X → 成功返回画廊，URL 恢复为 `/`
- 直接访问 `/photo/[id]` → 点击 X → 成功跳转到主页 `/`
