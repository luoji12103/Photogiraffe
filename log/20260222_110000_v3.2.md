# Photogiraffe v3.2 变更日志

## 版本信息
- 版本：v3.2
- 日期：2026-02-22
- 对应 Phase：Phase 3 Step 3

## 变更内容

### 新增

- **`frontend/src/lib/gl-renderer.ts`**（新建）  
  WebGL2 渲染器类，完整色彩调整管线：
  - Vertex Shader：全屏四边形（NDC [-1,+1]²），自动翻转 Y 坐标适配 WebGL
  - Fragment Shader：`sRGB → Linear → 曝光 → 亮度 → 对比度 → 饱和度 → sRGB`，使用 `highp float`
  - 支持两种纹理来源：`uploadFrame(RawFrame)` 和 `uploadImage(HTMLImageElement)`
  - 自动降级：WebGL2 → WebGL1 → `experimental-webgl`
  - `destroy()` 方法完整释放 GL 资源

- **`frontend/src/components/AdjustPanel.tsx`**（新建）  
  摄影调整滑块面板（4 个参数）：
  - Exposure（曝光）：-3 ~ +3 stops，步长 0.05
  - Brightness（亮度）：-1 ~ +1，步长 0.02
  - Contrast（对比度）：-1 ~ +1，步长 0.02
  - Saturation（饱和度）：0 ~ 2，步长 0.02
  - 已修改项高亮显示（蓝色数值），单项/全局重置按钮
  - 双击滑块重置单项

- **`frontend/src/components/GLCanvas.tsx`**（新建）  
  React 组件，封装 WebGL 渲染生命周期：
  - 首次 mount 时初始化 `GLRenderer`
  - `proxyUrl` 变化时加载 HTMLImageElement → 上传 GL 纹理
  - `rawFrame` 可用时替换纹理（无 UI 跳变）
  - `params` 变化时通过 `requestAnimationFrame` 触发重绘（60fps 流畅）
  - WebGL 不支持时自动降级为 `<img>` 标签

- **`frontend/src/lib/gl-renderer.ts`** 导出的 `AdjustParams` 接口 + `DEFAULT_ADJUST` 常量

### 修改

- **`frontend/src/components/PhotoDetail.tsx`**
  - 移除：`Image`（next/image）、`AnimatePresence`、`RawCanvas` 导入
  - 新增：`GLCanvas`、`AdjustPanel`、`AdjustParams`、`DEFAULT_ADJUST` 导入
  - 新增 `adjustParams` state（`useState<AdjustParams>(DEFAULT_ADJUST)`）
  - 图像区域：单一 `<GLCanvas proxyUrl rawFrame params />` 替代原有双层 WebP+RawCanvas 路径
  - 侧边栏：在 Details 区域下方新增 `<AdjustPanel>` 调整面板
  - 整体渲染路径统一，RAW 与 JPEG 都经过同一 GL pipeline

- **`frontend/outline/agent/19_Phase3_Step3_Plan.md`**（新增规划文档）

## 用户体验

打开任意照片详情页：  
1. GLCanvas 立即加载 WebP 代理图（HTTP 请求 → uploadImage → 首帧渲染）  
2. 侧边栏出现四个调整滑块，实时拖动生效（60fps，无 GPU 外数据重传）  
3. 若为 RAW 文件：后台 WASM 解码完成后无缝替换 GL 纹理，质量标签切换到 "RAW Native"  
4. 调整参数在组件销毁时清空（不持久化，后续可扩展保存）

## 技术亮点

- **统一渲染路径**：所有图像格式（RAW/JPEG/HEIF）都经过同一 WebGL pipeline，确保 Adjustment 对所有图片生效
- **零重新上传**：参数变更只更新 `uniform`，不重新上传纹理，帧率稳定
- **graceful degradation**：WebGL 不支持时自动 fallback 到 `<img src>` 静态显示  
- **内存管理**：`destroy()` 钩子在组件卸载时完整释放 WebGL context
