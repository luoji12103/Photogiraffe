## 目标
实现调色参数预设的保存、应用和删除功能，让用户可以离线保存常用滤镜并在不同照片间复用。

---

## 新增文件

### `go-core/models/models.go`  
- 新增 `Preset` 结构体：`UserID`, `Name`, `Description`, `AdjustParams (jsonb)`

### `frontend/src/app/api/presets/route.ts`  
- GET: 代理 go-core `/api/presets`  
- POST: 代理 go-core `/api/presets`（创建预设）

### `frontend/src/app/api/presets/[id]/route.ts`  
- DELETE: 代理 go-core `/api/presets/:id`

### `frontend/src/components/PresetPanel.tsx`（新建）
- 折叠 Accordion 面板（与 ExportPanel 同风格）
- 展开时自动 fetch 预设列表
- 预设项：点击应用调色参数（蓝色活跃状态）+ 悬停删除按钮
- "Save current as preset" 按钮 → 内联表单（名称 + 描述 + 保存/取消）
- 状态：idle / loading / saving
- 删除后即时更新列表，撤销活跃状态

---

## 修改文件

### `go-core/database/db.go`  
- AutoMigrate 增加 `Preset`

### `go-core/main.go`  
- 新增 3 个 API 端点：
  - `POST /api/presets` — 创建预设（带 adjust_params JSON 验证）
  - `GET  /api/presets` — 列出预设（created_at desc）
  - `DELETE /api/presets/:id` — 删除（软删除 via GORM）

### `frontend/src/components/PhotoDetail.tsx`
- import `PresetPanel`
- 在 AdjustPanel 和 ExportPanel 之间添加 `<PresetPanel params={adjustParams} onApply={setAdjustParams} />`

## 操作流程
```
用户在 AdjustPanel 调整参数
    │ 点击 "Save current as preset"
    ▼
PresetPanel 表单: 输入名称 → POST /api/presets {name, adjust_params}
    │
    ▼
Preset 保存到 PostgreSQL (presets 表)
    │
    ▼
下次打开同一或不同照片 → 展开 PresetPanel → 点击预设名 → AdjustParams 更新 → WebGL 实时重渲染
```
