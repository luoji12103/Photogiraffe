## 目标

增强预设系统，支持：
1. **平台标签** — 每个预设可标注适用软件（Lightroom / Capture One / Darktable 等）
2. **预设文件上传/下载** — 将原始预设文件（.xmp / .lrtemplate 等）存入 MinIO，可下载
3. **跨照片应用预设** — 在照片详情页应用预设时，持久化到后端（`photos.applied_preset_id`）

## PresetPanel 重写详情

**新增 interface 字段：**
```typescript
interface PresetRecord {
  Platforms: string; // JSON array string
  FilePath: string;  // empty = no file attached
}
interface PresetPanelProps {
  photoId?: number;  // if provided, persists apply to backend
}
```

**新功能：**
1. **平台标签保存** — save form 展示 6 个平台 chip（可多选），存为 JSON array
2. **平台标签展示** — 每张预设卡片下方以灰色 chip 显示适用平台
3. **预设文件上传** — 每个无文件的预设显示 Upload 按钮（点击弹出 file picker）
4. **预设文件下载** — 已上传文件的预设显示 Download 按钮（打开 presigned URL 新窗口）
5. **持久化应用** — 当 `photoId` 存在时，点击"Apply"同时 POST `/api/presets/:id/apply/:photoId`，将应用关系存入数据库
