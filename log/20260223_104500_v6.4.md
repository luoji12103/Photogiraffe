# v6.4 — 批量操作（Batch Operations）

**日期**: 2026-02-23  
**版本**: v6.4  
**分支**: s4.6full-stack

---

## 目标

允许用户在相册首页通过多选模式批量删除或批量导出照片，提升大量照片管理效率。

---

## 后端变更（go-core）

### `main.go` — 新增 2 条路由

#### `POST /api/photos/batch-delete`
- 请求体：`{"ids": [1, 2, 3]}`
- 最大 100 张/批次
- 鉴权：JWT (SuperAdmin 可删除任意用户照片，StandardUser 仅删除自己的)
- 删除 MinIO 三个变体（raw/proxy/thumb）+ GORM 软删除 DB 记录
- 响应：`{"deleted": N, "requested": M}`

#### `POST /api/photos/batch-export`
- 请求体：`{"ids": [1, 2, 3], "format": "jpeg"}`
- 最大 50 张/批次，仅 status=completed 的照片
- 对每张照片创建 `ExportJob` 并推送 Redis Stream 任务
- 响应：`{"queued": N, "jobs": [{"photo_id": X, "job_id": Y}, ...]}`

## 前端变更（frontend）

### 新增文件
- `src/app/api/photos/batch-delete/route.ts` — POST 代理至 Go Core
- `src/app/api/photos/batch-export/route.ts` — POST 代理至 Go Core
- `src/components/BatchActionBar.tsx` — 浮动批量操作栏（选中数量、导出按钮、删除按钮、清除选择）

### 修改文件

#### `src/components/PhotoGrid.tsx`
- 新增 props：`selectable?: boolean`, `selectedIds?: Set<number>`, `onToggle?: (id: number) => void`
- `selectable=true` 时：点击照片切换选中状态（不再跳转），选中时显示 `CheckCircle2` 图标 + sky-400 边框
- 未选中时 hover 显示 `Circle` 图标提示可选
- 选中状态禁用 framer-motion `layoutId`（避免 SharedLayout 冲突）

#### `src/app/page.tsx`
- 新增 state：`selectable`, `selectedIds` (Set<number>), `batchDeleting`, `batchExporting`
- 新增 handlers：`handleToggleSelect`, `handleClearSelection`, `handleBatchDelete`, `handleBatchExport`
- header 新增 "Select / Done" 切换按钮（CheckSquare 图标，激活时 sky 高亮）
- `PhotoGrid` 接收 `selectable`, `selectedIds`, `onToggle` props
- 页面底部渲染 `BatchActionBar`

## 测试结果

```bash
# 批量导出 2 张照片（真实 ID）
curl -s -X POST http://localhost:8080/api/photos/batch-export \
  -H "Authorization: Bearer $ACCESS" \
  -H "Content-Type: application/json" \
  -d '{"ids":[18,17],"format":"jpeg"}'
# → {"jobs":[{"photo_id":17,"job_id":1},{"photo_id":18,"job_id":2}],"queued":2} ✓

# 批量删除安全测试（不存在的 ID）
curl -s -X POST http://localhost:8080/api/photos/batch-delete \
  -H "Authorization: Bearer $ACCESS" \
  -H "Content-Type: application/json" \
  -d '{"ids":[999,998]}'
# → {"deleted":0,"requested":2} ✓

# 前端代理测试
curl -s -X POST http://localhost:3000/api/photos/batch-export \
  -H "Authorization: Bearer $ACCESS" \
  -H "Content-Type: application/json" \
  -d '{"ids":[18],"format":"jpeg"}'
# → {"jobs":[{"photo_id":18,"job_id":3}],"queued":1} ✓
```
