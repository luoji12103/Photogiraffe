## 目标
实现端到端的照片无损导出引擎：前端选项面板 → Go Core 任务创建 → Redis 队列 → Python Worker 处理 → MinIO 存储 → 前端下载链接。

### `python-worker/main.py`
- 新增 `EXPORT_STREAM_NAME = "export_queue"` 常量
- `init_redis()` 增加 `export_queue` consumer group 创建
- 新增 `_apply_adjust_params(img, opts)` — 镜像 WebGL shader 的 NumPy 色彩调整管线

- 新增 `_apply_watermark(img, minio_client, watermark_path, opacity, position)` — alpha 合成水印
- 新增 `process_export_task(minio_client, job_id, photo_id, opts_json)` — 完整导出管线
- 新增 `_update_export_status(job_id, status, output_path, error_message)` — 内部 API 回调
- 更新主循环：xreadgroup 包含 `export_queue`，分发 export 消息

## 技术决策
- **色彩调整管线**：Python NumPy 实现与 WebGL 片段着色器完全一致（同样的 sRGB/linear 转换、0.18 中灰对比度、Rec.709 luma 饱和度）确保"所见即所得"
- **水印**：Alpha 通道 paste 而非混合，精确保留透明区域
- **EXIF 保留**：使用 `piexif` 注入到 JPEG；原始 EXIF 字节从 Pillow `img.info["exif"]` 获取
- **presigned URL**：Go Core 生成 15 分钟有效期的签名 URL，前端直接用于下载（不经过 Next.js 流）
