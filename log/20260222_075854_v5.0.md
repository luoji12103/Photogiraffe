## 架构设计要点

### Token 存储策略
- **access_token**: 存于 React state（内存），15 分钟有效期，自动刷新
- **refresh_token**: httpOnly + SameSite=Strict Cookie，7 天有效，旋转式刷新

### 首位用户自动成为 SuperAdmin
```go
db.Model(&models.User{}).Count(&count)
if count == 0 { role = "SuperAdmin" }
```

### authFetch 自动刷新机制
- 收到 401 → 调用 /api/auth/refresh → 刷新成功后重试原请求
- 单例 `refreshPromise` 防止并发刷新竞态

### RBAC
- `requireJWT()`: 验证 Bearer token，注入 userID/username/role 到 Locals
- `requireRole("SuperAdmin")`: 检查 Locals 中的 role
- /api/config/ai 限定 SuperAdmin
