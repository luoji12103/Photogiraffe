## go-core 新增路由

| 路由 | 权限 | 说明 |
|------|------|------|
| `GET /api/admin/flags` | SuperAdmin | 列出全部 Feature Flags |
| `PUT /api/admin/flags/:name` | SuperAdmin | 切换 Feature Flag 开关 |
| `GET /api/feature/:name` | JWT 任意用户 | 查询单个 Feature Flag 状态 |
| `GET /api/admin/users` | SuperAdmin | 列出全部用户 |
