### v13.1 — Go Core 模型 + IPTC API（3 个新端点）

**数据模型变更**（`go-core/models/models.go`）：
```go
type ExifData struct {
    ...（原有字段）...
    // IPTC / XMP fields (Phase 13)
    Copyright string // dc:rights / EXIF Copyright
    Creator   string // dc:creator / EXIF Artist
}
```
GORM AutoMigrate 在下次启动时自动为 `exif_data` 表增加 `copyright` 和 `creator` 列。

**新增 API 端点**（`go-core/main.go`）：

| Method | Path | Auth | 说明 |
|--------|------|------|------|
| GET | `/api/photos/:id/iptc` | JWT（同属/SuperAdmin）| 返回 photo_id、description、copyright、creator |
| PUT | `/api/photos/:id/iptc` | JWT（同属）| 更新 copyright + creator，FirstOrCreate ExifData 记录 |
| GET | `/internal/photos/:id/iptc` | X-Internal-Secret | Worker 无 JWT 访问版，同样返回以上字段 |

**前端代理路由**（`frontend/src/app/api/photos/[id]/iptc/route.ts`）：
- GET 和 PUT 均透传 Authorization 头到 Go Core

### v13.2 — Python Worker 上传管道 XMP 提取

在 `process_image()` 的 EXIF 提取之后，ICC 颜色处理之前，加入 XMP 扫描：

```python
# 正则扫描 JPEG/RAW raw bytes 中的 XMP 包
xmp_match = re.search(rb'<x:xmpmeta[\s\S]*?</x:xmpmeta>', img_data)
if xmp_match:
    xmp_str = xmp_match.group(0).decode("utf-8", errors="ignore")
    # dc:rights → Copyright
    cr = re.search(r'<dc:rights[^>]*>[\s\S]*?<rdf:li[^>]*>([\s\S]*?)</rdf:li>', xmp_str)
    # dc:creator → Creator
    au = re.search(r'<dc:creator[^>]*>[\s\S]*?<rdf:li[^>]*>([\s\S]*?)</rdf:li>', xmp_str)
```

提取的 `Copyright` 和 `Creator` 注入 `exif_data` 字典，随 `PUT /internal/photos/:id/status` 回调自动存入数据库。

### v13.3 — Python Worker 导出管道 IPTC 写入

在 `process_export_task()` 的 JPEG 输出分支，替换原有的 `piexif.load(orig_exif_bytes)` 独立块：

1. **获取 IPTC 数据**：`GET {GO_CORE_URL}/internal/photos/{photo_id}/iptc`（X-Internal-Secret）
2. **构建 exif_dict**：若有原始 EXIF 字节则 `piexif.load()`，否则创建空白 `{"0th":{}, "Exif":{}, "GPS":{}}`
3. **注入 IFD0 字段**：
   ```python
   exif_dict["0th"][piexif.ImageIFD.Copyright]       = copyright.encode("latin-1")
   exif_dict["0th"][piexif.ImageIFD.Artist]           = creator.encode("latin-1")
   exif_dict["0th"][piexif.ImageIFD.ImageDescription] = description.encode("latin-1")
   ```
4. `piexif.dump(exif_dict)` → `save_kwargs["exif"]`

**优化点**：即使 `embed_exif=False` 或原始文件无 EXIF，只要 copyright/creator 非空仍会写入。

## 编译修复

初次构建报错：
```
invalid operation: photo.ExifData != nil (mismatched types models.ExifData and untyped nil)
```

`Photo.ExifData` 是**值类型**（非指针），不能与 nil 比较。修复方法：去除 nil 判断，直接读字段（零值为空字符串，无影响）。
