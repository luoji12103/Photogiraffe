## 目标
根据 `20_Phase3_Step4_Plan.md`，实现宽色域/HDR 显示适配：
1. 检测用户显示器的色域与 HDR 能力
2. 以正确的 `colorSpace` 初始化 WebGL canvas（Display P3 / sRGB）
3. 将 ACES filmic 色调映射加入 Fragment Shader
4. 展示色彩空间指示器徽章

---

## 新增文件

### `frontend/src/lib/display-detect.ts`
- 使用 `window.matchMedia` 检测 `(color-gamut: p3)`、`(color-gamut: rec2020)`、`(dynamic-range: high)`
- 返回 `DisplayCapabilities` 接口：`{ isP3, isRec2020, prefersHDR, targetColorSpace }`
- 热插拔支持：通过 `MediaQueryList.addEventListener("change", ...)` 监听显示器变化
- SSR 安全：先检查 `typeof window`

### `frontend/src/components/ColorSpaceIndicator.tsx`
- 接收 `DisplayCapabilities` 参数
- P3 显示器 → 紫色徽章 "Display P3"
- sRGB 显示器 → 蓝色徽章 "sRGB"
- HDR 显示器额外显示琥珀色 "HDR" 标签

---

## 修改文件

### `frontend/src/lib/gl-renderer.ts`
- `AdjustParams` 新增 `tonemap: boolean`（默认 `false`）
- Fragment Shader 新增：
  - `uniform float u_tonemap`
  - `acesFilmic()` 函数（ACES filmic 近似：`(x*(2.51x+0.03))/(x*(2.43x+0.59)+0.14)`）
  - `linear = mix(linear, acesFilmic(linear), u_tonemap)` — 用 `mix()` 避免 shader 分支
- `render()` 新增 `set1("u_tonemap", params.tonemap ? 1.0 : 0.0)`
- `init()` 新增可选 `colorSpace: "srgb" | "display-p3"` 参数，传入 `getContext()`

### `frontend/src/components/AdjustPanel.tsx`
- 新增 `NumericAdjustKey` 类型（避免 `boolean` 字段影响滑块逻辑）
- 新增 `toggleTonemap` 回调
- 在滑块列表下方添加 ACES 切换开关（toggle button）
- `isDefault` 检查包含 `tonemap`

### `frontend/src/components/GLCanvas.tsx`
- 新增 `colorSpace?: "srgb" | "display-p3"` prop
- `useEffect` 依赖 `colorSpace`：当色彩空间变化时销毁并重建 GL context
- 将 `colorSpace` 传入 `GLRenderer.init()`

### `frontend/src/components/PhotoDetail.tsx`
- 新增 import：`useDisplayDetect`、`ColorSpaceIndicator`
- 调用 `useDisplayDetect()` 获取 `display` 状态
- 将 `colorSpace={display.targetColorSpace}` 传入 `<GLCanvas>`
- 在图片区右下角绝对定位 `<ColorSpaceIndicator caps={display} />`

## 技术决策
- 使用 `mix(linear, acesFilmic(linear), u_tonemap)` 而非 `if`，避免 GPU shader 分支发散
- WebGL context `colorSpace` 选项：浏览器在支持时会直接将 canvas 输出映射到 Display P3
- `useEffect` 依赖 `colorSpace` 以便热插拔显示器时自动重建 context
