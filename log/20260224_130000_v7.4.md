# v7.4 — 用户档案与摄影师身份 (2026-02-24 13:00)

## 目标
建立摄影师个人档案体系：头像上传、个人签名图管理（透明 PNG）、简介/网站/城市编辑，为后续导出水印叠加打下基础。

## 实现内容

### 1. 数据模型 (`go-core/models/models.go`)
```go
type UserProfile struct {
    gorm.Model
    UserID        uint   `gorm:"not null;uniqueIndex"` // 一对一关联 users.id
    Bio           string `gorm:"type:text"`
    AvatarPath    string // MinIO: "profiles/avatars/{uid}/{uuid}.ext"
    SignaturePath string // MinIO: "profiles/signatures/{uid}/{uuid}.png"
    Website       string
    Location      string
}
```
- AutoMigrate 自动建表（`go-core/database/db.go`）

### 2. 后端 API (`go-core/main.go` — 4 个端点)
| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/api/profile` | 获取档案（若不存在则 FirstOrCreate），返回含 1h 预签名 avatar/signature URL |
| PUT | `/api/profile` | 更新 bio／website／location |
| POST | `/api/profile/avatar` | 上传头像（multipart `avatar` 字段），存入 MinIO `profiles/avatars/` |
| POST | `/api/profile/signature` | 上传签名图（multipart `signature` 字段，Content-Type 强制为 `image/png`），存入 `profiles/signatures/` |

### 3. 前端 API 代理
- `api/profile/route.ts` — GET + PUT
- `api/profile/avatar/route.ts` — POST（转发 FormData）
- `api/profile/signature/route.ts` — POST（转发 FormData）

### 4. 档案页面 (`frontend/src/app/profile/page.tsx`)
- **头像区**：圆形预览（80×80）+ 点击上传；支持 JPG/PNG/WEBP
- **个人信息区**：bio（4 行 textarea）、website（url 输入）、location（文字输入）一键保存
- **签名图区**：
  - 格子背景透视层（可视化透明通道）
  - 24×80px 预览区
  - 点击上传 PNG/WEBP 文件
  - 移除按钮（前端清除预览）
- 保存状态：Loader2 → 绿色 Check "已保存"（2.5 s 后重置）

### 5. ClientLayout 导航 (`frontend/src/components/ClientLayout.tsx`)
- 新增 `UserCircle` import
- Albums 链接之后添加 `/profile` 导航链接（所有已登录用户可见）
