## 交付概述

本阶段为导出引擎增加了**简约边框/相框渲染**功能，支持在导出图片时自动在照片外围生成包含拍摄参数、AI 分析、照片描述的信息栏，并能适配多种画布比例（16:9 / 4:3 / 3:2 / 1:1 / 16:10 / 4:5 / 3:4 / 21:9 / 原始比例）进行动态布局。

## v15.2 Worker — 边框渲染引擎

**文件**：`python-worker/main.py`

### 2.1 PIL 导入扩展

```python
from PIL import Image, ImageCms, ImageDraw, ImageFont
```

新增 `ImageDraw`、`ImageFont`——Pillow 内置，无需新增 pip 依赖。

### 2.2 常量定义

| 常量 | 说明 |
|------|------|
| `_CANVAS_RATIOS` | 9 种目标画布比例（"original" / "16:9" / "4:3" / "3:2" / "1:1" / "16:10" / "4:5" / "3:4" / "21:9"）|
| `_FRAME_THEMES` | 3 种主题（white / dark / film），每种含 bg/primary/secondary/divider/accent 5 色 |
| `_FONT_SEARCH_PATHS` | 6 个 Linux 系统 TrueType 常规字体路径（含 NotoSans、DejaVu、Ubuntu 等）|
| `_FONT_BOLD_PATHS` | 6 个 Linux 系统 TrueType 粗体字体路径 |

### 2.3 工具函数

| 函数 | 作用 |
|------|------|
| `_try_font(size, bold)` | 遍历系统字体路径加载 TrueType，失败时返回 PIL 内置默认字体 |
| `_text_bbox(draw, text, font)` | 测量文字宽高，兼容旧版 Pillow |
| `_fit_text(text, font, max_w, draw)` | 按最大宽度截断并补省略号 |
| `_wrap_text(text, font, max_w, draw, max_lines)` | 按词边界换行，最多 max_lines 行 |
| `_fetch_photo_meta(photo_id)` | 通过 `X-Internal-Secret` 请求 `/internal/photos/{id}/meta`，返回 dict |

### 2.4 核心渲染函数 `_render_frame(img, meta, opts)`

**输入**：
- `img`：待处理的 PIL Image
- `meta`：来自 `_fetch_photo_meta` 的字典
- `opts`：导出选项（含 frame_style / frame_ratio / frame_show_exif / frame_show_desc / frame_show_ai）

**布局决策逻辑**：

```
photo_ratio = W / H
target_ratio = _CANVAS_RATIOS[opts["frame_ratio"]]

use_side_layout = (photo_ratio < 0.85) AND (target_ratio > 1.0 OR target_ratio == 0.0)
```

- **Bottom 布局**（横向照片 OR 方形目标）：照片居上，信息栏居下，二者之间水平分割线
- **Side 布局**（竖向照片 + 宽幅目标）：照片居左，竖向分割线，信息列居右

**文字排版**：

| 类型 | 字号比例 | 最小 |
|------|---------|------|
| 主要粗体（相机/镜头）| 短边 × 2.2% | 14px |
| 次要常规（EXIF 参数）| 短边 × 1.75% | 12px |
| 描述/AI 小字 | 短边 × 1.4% | 11px |

- 外边距 = 短边 × 4.5%（最小 24px）
- 版权字段右对齐显示于信息区右下角
- AI 分析：提取 `ai_analysis` JSON 中 `summary` 字段，限 3 行
- 全部文字渲染包裹在 try/except 中，任何字体/布局错误均静默跳过（graceful degradation）

**画布扩展**：自然尺寸计算完成后，按目标比例扩展宽度或高度，将原始照片嵌入然后填充信息区。

### 2.5 步骤 5b — 集成到导出流程

在 `process_export_task` 中，水印叠加（step 5a）之后、输出 bytes 之前插入：

```python
frame_style = opts.get("frame_style", "")
if frame_style and frame_style not in ("none", "off", ""):
    frame_meta = _fetch_photo_meta(photo_id)
    img = _render_frame(img, frame_meta, opts)
```

未启用边框时性能开销为零（无额外 HTTP 请求）。

## 架构说明

```
导出任务流程（Phase 15 新增步骤）：

process_export_task():
  step 1: 下载原始文件
  step 2: 解码/色彩调整
  step 3: 分辨率缩放
  step 4: 格式转换
  step 5a: 水印叠加（已有）
  step 5b: [NEW] 边框渲染
    └── _fetch_photo_meta() → GET /internal/photos/:id/meta
    └── _render_frame(img, meta, opts)
        ├─ 底部信息栏（横向照片）
        └─ 侧边信息栏（竖向照片 + 宽幅目标）
  step 6: 输出 bytes → MinIO exports/
```
