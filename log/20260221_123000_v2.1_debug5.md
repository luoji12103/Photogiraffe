# 日志: 2026-02-21 12:30:00 (v2.1_debug5)

## 问题描述
在照片详情页点击 "Analyze Photo" 按钮后，loading 动画持续转圈不停止，浏览器控制台不断报错：
```
GET http://localhost:3000/api/photos/8 500 (Internal Server Error)
```

---

## 根因

### URL 路径前缀不匹配
Next.js 轮询路由 `frontend/src/app/api/photos/[id]/route.ts` 将 GET 请求转发到 go-core 时，使用了错误的路径：

```ts
// 错误
fetch(`${internalApiUrl}/api/photos/${id}`)

// go-core 实际路由
app.Get("/photos/:id", ...)   // 无 /api 前缀
```

go-core 的 `/api/photos/:id` 路由不存在，返回 404 → Next.js 路由捕获到 `res.ok === false` 后返回 500 给浏览器。

### 后果
`PhotoDetail.tsx` 中的 polling 逻辑检测 `checkRes.ok`，500 一直为 false → `clearInterval` 永远不触发 → 转圈到 60 秒超时。

---

## 修复方案

只需修正 `frontend/src/app/api/photos/[id]/route.ts` 中的路径，移除多余的 `/api` 前缀：

```ts
// 修复后
const res = await fetch(`${internalApiUrl}/photos/${id}`, {
  cache: "no-store",
});
```

---

## 修改文件清单
- `frontend/src/app/api/photos/[id]/route.ts`：URL 从 `/api/photos/${id}` 改为 `/photos/${id}`

## 验证结果
- `GET http://localhost:3000/api/photos/11` → HTTP 200，正确返回照片数据（含 `AIAnalysis` 字段）
- `POST http://localhost:3000/api/photos/11/analyze` → `{"message":"AI analysis task queued successfully"}`
- 点击 Analyze Photo 后任务成功入队，python-worker 会消费 `ai_analysis_queue` 进行 AI 分析，完成后轮询拿到结果并停止 loading
